Коллектор
Обмотка? Значения. Z — число пазов (чётное); u — секций (катушек) на паз; yк — шаг по коллектору.

Отношения. SEG = Z·u — число ламелей и число секций обмотки; y1 = Z/2 — полный шаг по пазам (двуслойная петлевая обмотка, 2p = 2).

Формулы. секция c занимает верхний слой в пазу ⌊c/u⌋ и нижний — в пазу (⌊c/u⌋ + Z/2) mod Z; её конец идёт на ламель (c + yк) mod SEG.

Условие. Один замкнутый контур обмотки — при gcd(yк, SEG) = 1. Диапазоны: SEG ∈ [6, 48]; 1 ≤ yк < SEG; u ∈ [1, 4].
